# קודי התרעה בלוח המחוונים

כשמערכת ברכב מזהה בעיה, נדלקת נורית בלוח המחוונים, ובמסך מופיע קוד התרעה. הטבלה מסבירה מה כל קוד אומר ומה צריך לעשות. נורית אדומה פירושה שיש לעצור בהקדם. נורית צהובה פירושה שיש להגיע למוסך בימים הקרובים.

## טבלת הקודים

| קוד | הנורית בלוח המחוונים | המשמעות | מה עושים |
|---|---|---|---|
| E-11 | נורית מנוע צהובה | תקלה בחיישן פליטה | להגיע למוסך בימים הקרובים |
| E-14 | נורית מצבר | תקלה בטעינת המצבר | לבדוק במוסך בהקדם |
| E-17 | סמל צמיג | לחץ אוויר נמוך באחד הצמיגים | לבדוק ולנפח בתחנת דלק |
| E-19 | סמל טיפה כתומה | מפלס נמוך של נוזל שמשות | למלא נוזל שמשות |
| E-23 | מד חום אדום | טמפרטורת מנוע גבוהה | לעצור, לכבות את המנוע ולהמתין שיתקרר |
| E-26 | סמל קנקן שמן אדום | לחץ שמן נמוך | לעצור מיד ולא להמשיך בנסיעה |
| E-28 | סמל ABS | תקלה במערכת למניעת נעילת גלגלים | הבלמים פועלים, אבל יש להגיע למוסך |
| E-31 | נורית בלם אדומה | תקלה במערכת הבלימה או מפלס נמוך של נוזל בלמים | לעצור בצד בבטחה ולהזמין גרר |
| E-34 | סמל תקע | תקלה בטעינת רכב חשמלי | לנסות עמדת טעינה אחרת |
| E-37 | סמל הגה | תקלה בהגה הכוח | לנסוע לאט עד המוסך הקרוב |
| E-40 | סמל כרית אוויר | תקלה במערכת כריות האוויר | להגיע למוסך בהקדם |
| E-45 | סמל מפתח | הגיע מועד הטיפול התקופתי | לקבוע תור לטיפול |
